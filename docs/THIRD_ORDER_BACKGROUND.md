# 三阶背景路线：精确公理与待证上界

日期：2026-09-14。用户已允许选用强于 Z₂ 而不过度增强的三阶算术子系统
或其他标准背景，并要求保留原 ZFC／可构造层次证明版。本文固定本轮
工作目标，**不宣称 BM4 的降背景证明已完成**。

## 1. 工作背景

采用集合论呈现

\[
T_3^{\mathrm{set}}=\mathrm{ZF}^{-}_{\mathrm{Sep,Coll}}
 +\mathrm{WOChoice}+\exists\mathcal P(\omega)
 +\forall A\,(A\hookrightarrow\mathcal P(\omega)).
\]

其中无幂集核心保留外延、空集、配对、并集、无穷、正则、完整分离与完整
收集。WOChoice 明确要求每个集合有一个内部集合关系良序，而非未经证明
与之等价的选择集变体。规模界为连续统 beth₁，不默默假定 CH 或替换成
aleph₁。幂集存在只用于 ω，不允许对任意集合应用完整幂集公理。

`PowerlessTheory.axiom_m` 的外延公理先以同一 Project 正文给出结构性的
闭合证明，以免依赖需要外延性才能使用的语义桥；其余五条基础闭句复用
已核验的纯语言公理，经上游反向语法桥提供非原生的闭合证书。分离与收集直接使用上游 Project
模式，随后沿已有 `fo_theory` 进入唯一纯集合论签名 ℒ。`ThirdOrderTheory` 用同一签名
表达幂集、内部集合单射和内部子集极小元；没有新的源语法内核。

## 2. 文献依据与证据边界

Cheng–Schindler 的 Definition 1.4 明确采用删除幂集、以 Collection 取代
Replacement 的 ZFC⁻；其三阶版本加 P(ω) 存在和每个集合大小至多 beth₁，
并指出该系统可证明 H_{ω₁} 满足其二阶集合论版本。[原文，第 1 页](https://arxiv.org/pdf/1503.04000)

这给出了标准有限阶背景的工作依据，不自动提供本仓库的类型化 Z₃ 解释
或 BM4 定理。文献的集合模型结论给出 Z₃ ⊢ Con(Z₂)，因此该完整背景
不能与纯无幂集核心混同为二阶算术等一致。此处是引用文献的数学比较，
不是本仓库已经形式化的强度定理；也不表示只增强一条一致性句就够用。

McLarty 另给出有限次幂集与高阶算术的解释路线，可作后续对照；其不同
无幂集理论的 Replacement／Collection 呈现不能直接混用。[原文](https://arxiv.org/pdf/1207.6357)

## 3. 为什么值得尝试

在原 Z₂ 解释中，可数集合论的整个环境通常只是解释类。对全部内部公式
同时取环境真谓词或同时选各级反射见证，不能当作一个已有集合操作。

新的工作设想是利用一个作为集合存在的 H_{ω₁} 或适当可构造子结构，
在更大环境中为它构造满足关系，再统一处理内部公式编号和有限高度。
这是**拟证明的规约**，尚不能据此断言所有稳定对或 BM4 良序性已获得。

初步拆分需要逐项完成：

1. 在明确公理中构造 H_{ω₁}，验证它所满足的二阶集合论、闭包和相关
   数值编码；处理任意环境下降实数的保留。
2. 构造该集合结构的统一满足关系；解释中的内部良基不能替换为外部 Acc。
3. 为适当 L* 或相对构造域证明所需收集、反射及 proper 稳定见证。集合
   结构真谓词不是整个环境宇宙的真谓词。
4. 接入原 BM4 检查器、展开与固定高度目标，形成一个无未消去前提的新
   主定理，并审查该背景是否还能进一步弱化。

旧候选 Z₂ + RFN_{Π¹₁}(Z₂) 保留为较低的有条件路线。若采用它，仍需
实际原始递归证明生成器及 PRA 的 `(G)`；切换三阶工作背景不会自动完成
或证明不再需要旧路线的义务。

## 6. 优先核验的构造：环境内部的 L_{ω₁}

以下是本轮提出并送审的规约，不是已完成的对象证明。它尝试直接使用
环境的首个不可数序数 κ，避免先解决旧 Z₂ 路线整个解释类的真谓词。
H_{ω₁} 路线保留为理论解释的对照，但不预先要求它成为 BM4 证明的入口。

1. **κ 的集合存在与可数取界。** 现已完成集合存在部分：良序化 P(ω)，
   用无幂集核心中已证的内部坍缩取其序型，再分离出最小不可数序数 κ。
   这条实际实现不需要先构造可数良序编码空间；旧编码规约保留为备选。
   随后用实际内部三角数编码、WOChoice 与收集证明可数并可数，再证明
   κ 对集合后继封闭，以及每个可数域上的 κ 值函数有 κ 内严格上界。
   这已给出后续规约所需的可数取界性质；不调用 Lean 的 ω₁ 或外部正则性。
2. **层次本身是集合。** 用完整收集构造内部可构造递归，逐级核验
   α<κ 时 L_α 可数；后继级从公式码及有限参数枚举 Def(L_α)，不是
   任取 P(L_α)。必须实际证明 Def 的规模界，并沿全部内部 α<κ 递归
   构造 L_α↪ω；“α<κ”本身不是逐级可数性的证明。收集各级再取并
   得到实际集合 L_κ。
   这一步不声称任意弱集合论中的整个 L 都满足 Collection。
3. **集合结构的统一真值。** 对 L_κ 的内部公式码及有限赋值构造实际
   满足关系。所需有限序列空间由乘积、ω 递归与收集得到，满足关系由
   内部语法递归得到；不假定 P(L_κ) 存在，也不构造环境宇宙真谓词。
4. **proper 初等层。** 若前三步闭合，对每个 β<κ，遍历所有内部
   存在公式码及 L_β 中的有限参数，选择它们在 L_κ 中的见证。参数域
   可数，所以见证所在级数有共同上界 F(β)<κ。让 F(β)>β，作 ω 次
   闭包并取极限 α<κ；内部 Tarski–Vaught 检查应给出 L_α≺L_κ。
   从任意更高起点再作一次闭包，可得 α<β<κ 且 L_α≺L_β。
   这里“对全部公式同时”必须消费第三步的同一个集合满足关系，不能
   用对每个外部标准公式分别反射代替。这里的统一范围限于 L_κ 这个
   集合结构，不宣称已得到跨环境全部可构造层次的同一稳定对。
5. **有限层边界与 BM4。** 从上述 proper pair 为每个内部有限 n
   定义在 κ 以下具有第 n 层稳定后继的最小下端点。验证边界以下
   的稳定关系层号截断、种子标签及展开保持，然后在环境中定义记号
   的最小标签界。现有 `FiniteStableBoundary` 已核验的是宿主序数版本；
   这里仍须把同一实际检查器与内部数、数组、公式和序数逐项连接，
   并从第 4 步的集合级统一推出全部内部 n 的边界存在，不能逐个外部 n 替代。
6. **保留任意下降实数。** 对环境中的任意候选下降序列 X，在环境中
   收集它的最小标签界，使用环境内部序数的良序性排除下降。此计划
   不要求 X∈L_κ，但必须实际证明标签函数定义在环境编码的全部相关
   记号上。仅有“L_κ 认为 BM4 良序”不足以得出环境结论；更不能从
   内部良基直接取得宿主 `Acc`。

其中 1 已核验；2–4 已在实际 C 层次上完成集合构造、统一求值及相对 Cκ
的共尾初等层，见第 17–21 节。C 与经典 L 的所需对应、两个早级间的
proper pair 装配及 5–6 仍有证明义务，不是引用文献已给出的完整 BM4 三阶定理。

向三阶算术翻译列为后续工作，而不是该论文已经证明的降背景结论。
[Hunter，§2–3](https://arxiv.org/html/2307.04606v3#S2)

若这条规约可闭合，最后还要单独核验本精确公理呈现与标准三阶算术的

## 10. 已完成的三角数编码与可数取界

采用三角数编码，只依赖已实现的内部加法，不搬运带完整 hZF 前提的
上游无限基数乘法证明。以下已进入实际 Lean 定理：

1. 在已存在的 P=ω×ω 上，以状态 (n,t) 迭代为 (n+1,t+(n+1))，从
   (0,0) 起始。纯一步公式在 P 外约定返回原输入，从而给出对所有模型
   对象总唯一的公式，适用现有内部 ω 递归；这不是新增递归公理。
   对应 `PowerlessTriangularStep`。
2. 对实际公式“第 n 项为 (n,t)，且 t∈ω”作内部归纳，得到坐标一致性。
   再从状态图投影出实际函数 T:ω→ω，核验 T(0)=0 与
   T(n+1)=T(n)+(n+1)。`PowerlessTriangularRecursion` 与
   `PowerlessTriangular.exists_l` 覆盖非标准内部 n。
3. 定义配对值 c=T(a+b)+a。由加法严格单调、消去及自然数可比性证明
   T(s)≤c<T(s+1)，其中 s=a+b；不同对角线的区间不交。同一对角线
   用左加数消去得到 a 相等，再得到 b 相等。`PowerlessPairingCode`
   证明这两类唯一性，`PowerlessNaturalPairing.exists_l` 构造实际 P→ω 单射。
4. `PowerlessProductMapping` 构造逐坐标作用的集合图；复合第 3 步，
   `ThirdOrderCountableUnion.product_l` 得到两个可数集合之积可数。
