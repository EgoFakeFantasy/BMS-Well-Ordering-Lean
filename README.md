一个轻量 Lean 4 项目。

## 形式化成果

[Lean 形式化奖杯表](TROPHIES.md)集中展示已经闭合的里程碑定理及其可复用基础设施。
当前首要里程碑是在对象元理论层闭合 ZFC 的纯语法 Rosser 不完备定理；奖杯表同时
列出 checked proof code、成功 replay 反演、对象证书 verifier、失败适配、Gödel
quotation、内部对角化和对象有限算术等支撑资产。
